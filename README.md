# certihom — Phases 0–3, exactly certified

Certified two-sided bounds on effective properties from neural admissible
fields — the falsifiable core of the research program *"Certified Amortized
Homogenization: Guaranteed Two-Sided Bounds on Effective Elasticity Tensors
from Operator-Learned Admissible Fields"*. Phase 0 implements 2D scalar
conductivity (every claim checkable against closed forms); **Phase 2 adds
the paper's tensorial novelty**: certified Loewner intervals
C_low ⪯ C_eff ⪯ C_up for full 2D elasticity tensors, with the lower bound
built from Airy-potential networks whose induced stresses are equilibrated
and mean-controlled *by construction*, plus certified intervals for
directional Young's moduli derived from the tensor bounds. **Phase 3 adds
amortization**: one operator, conditioned on the microstructure through
smooth in-graph Fourier features (the construction that preserves H¹
conformity — see MATH.md §10), certifies *unseen* microstructures at
~19 ms per certificate, with validity guaranteed even far out of
distribution and certificate width acting as a built-in trust signal.

**What it does.** For a periodic pixel microstructure k(y), two small
networks — a periodic temperature fluctuation (primal) and a periodic
stream function whose curl is an exactly divergence-free, exactly
mean-controlled flux (dual) — are trained *label-free* by minimizing energy
and complementary energy. Any admissible field pair yields matrices

    K_low ⪯ K_eff ⪯ K_up   (Loewner order),

so every training iterate carries a valid certificate; optimization affects
tightness only. Zero-initialized output layers make step 0 exactly the
classical Voigt–Reuss envelope. Derivations and proofs: `MATH.md`.

## Verification ladder (all must pass before any science)

1. **Homogeneous collapse** — zero fields ⇒ K_low = K_up = k₀I to 1e-12.
2. **Voigt–Reuss at step 0** — untrained networks reproduce ⟨k⟩ and
   ⟨1/k⟩⁻¹ exactly.
3. **Laminate, machine precision** — the closed-form optimal fields pushed
   through the *production* Gram assembly give K_low = K_up = K_exact to
   ~1e-12 (quadrature is provably exact for these fields).
4. **Arbitrary admissible fields still bracket** — random periodic Fourier
   trials must contain the exact laminate tensor: a bad model widens the
   interval, never invalidates it.
5. **Reference audit** — the periodic FV solver is itself tested (exact on
   laminates both axes, convergent to the Dykhne value on the
   checkerboard) before being allowed to audit anything.
6. **Training smoke** — bounds tighten from Voigt–Reuss, stay
   Loewner-valid, and keep containing the exact checkerboard tensor.
7. **Elasticity money test** — exact laminate per-phase states through the
   production Mandel Gram give C_up = C_low = C_exact to ~1e-11 (dual
   trials recombined to unit mean stress, MATH.md §9b).
8. **Conforming-FEM one-sided audit** — Q1 periodic FEM is itself an upper
   bound, so C_low ⪯ C_FEM(h) must hold at every mesh level with NO
   tolerance; the FEM module is itself certified exact on the laminate.
9. **Conditioned-formula pinning** — the amortized field formulas are
   bit-identical to the certified Phase 0/2 paths on shared networks.
10. **Amortized validity, ID and OOD** — held-out instances bracket the FV
    reference; unseen families and a 10× contrast shift bracket EXACT
    tensors, with no reference-solver slack.

## Phase roadmap

* **Phase 1 — exact-integration certificates: DELIVERED.** Q1 projection
  (scalar primal/dual, elasticity primal) and BFS bicubic-Hermite C¹
  projection (elasticity dual, Airy) with exact Gauss integration. All
  three anchored at machine precision against exact laminate solutions.
  The quadrature caveat is retired; measured price 0.1–3.0 points of width.
* **Phase 2 — elasticity: DELIVERED.** Strain-basis heads (C_up) + Airy
  stress potentials (C_low); certified engineering-constant intervals;
  conforming-FEM one-sided audits. See RESULTS.md.
* **Phase 3 — amortization: DELIVERED.** Smooth Fourier-feature
  conditioning (conformity-preserving) ⇒ certificates at inference cost;
  measured: ~1,340× speedup, 100% validity ID and OOD, width tracks shift
  severity. GPU-scale follow-ups: FiLM/CNN encoders, larger families,
  amortized elasticity at production sizes, warm-started hybrid refinement.
* **Phase 4 — applications:** certified inverse design DELIVERED (+57%
  guaranteed floor at fixed material budget); RVE statistics still open.
